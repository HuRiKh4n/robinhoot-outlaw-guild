# RobinHoot — The Outlaw Guild

Responsive NEAR-community website prototype built with Next.js and TypeScript.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Implemented
- Landing page, manifesto, five-chapter roadmap
- Interactive local-only outlaw character preview (emoji placeholders)
- Mobile-responsive layout

## Planned (not live)
- NEAR wallet sign-in / holder verification
- AI-generated character PFPs and downloadable WANTED posters
- Database-backed profiles, bounties and treasury distributions

Never enter a seed phrase. No transactions occur in this prototype.

## Deploy
Import this GitHub repository in Vercel; it will detect Next.js automatically. Configure the domain only after successful deployment.
