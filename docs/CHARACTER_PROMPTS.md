# Prompt per le immagini dei personaggi

Stile ricavato dalle 16 volpi approvate. Un prompt per ogni immagine mancante: copialo in ChatGPT (generazione immagini), formato verticale 2:3.
Totale: **84 immagini** (Lupo: solo Scout e Trickster; Procione, Coniglio, Tasso, Gufo, Orso: tutte le 16).


**Dove va il file:** salva l'immagine come PNG con il nome indicato in `public/characters/<specie>/<classe>/<outfit>.png`, poi esegui `npm run register:art` (o mandala a Claude nella chat: la registra lui). Il sito la mostra appena pubblicata.

Consiglio: genera prima un'immagine per specie, confrontala con le volpi e solo dopo fai le altre, così lo stile resta uniforme. Se un risultato taglia i piedi o le orecchie, chiedi di rigenerarla con più spazio intorno.
