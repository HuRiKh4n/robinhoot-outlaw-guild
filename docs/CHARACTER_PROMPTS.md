# Prompt per le immagini dei personaggi

Base comune a tutti (corpo intero, posa di tre quarti, medaglione bronzo, tessuti cuciti a mano). Ogni **outfit** ha palette, scarpe e luce sue; ogni **specie** ha un piccolo tocco di stile proprio (Tasso: robusto, polvere di pietra; Gufo: elegante, luce di luna e piume; Orso: imponente, neve e brina). Copia un prompt alla volta in ChatGPT, formato verticale 2:3.

**Dove va il file:** `public/characters/<specie>/<classe>/<outfit>.png`, poi `npm run register:art` (oppure manda le immagini a Claude in chat).

Già complete: Volpe, Procione, Coniglio (16 ciascuno), Lupo (12).
